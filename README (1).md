# results/

Outputs of the Kaggle run on 23 October 2026 (profile `full`, seed 42).

- `tables/` - Tables 1-8, per-fold metrics (`metrics_by_fold.csv`), paired statistics, uncertainty and robustness tables, SHAP drivers, Optuna parameters per fold, ensemble weights, decision gates, D3/D4 context tables.
- `figures/` - PNG figures. `Fig10_error_map_D1.png` is omitted because it is empty by construction (D1 has no coordinates). PDF versions are produced by the notebook but not stored here.
- `audit/` - per-dataset audit JSON, feature-block assignment, split availability.
- `repro/` - configuration, environment, dataset sources, feature sets, and train/validation/calibration/test indices of every split (`split_indices_*.npz`).
- `paper_tables.md` - generated by `scripts/summarize_results.py`.

Per-fold checkpoints (`ckpt/`, large pickles) are not included.
